# Cross-Document & Long-Range Consistency V1

## الهدف

اختبار قدرة نَضِيد على اكتشاف التعارضات التي تفصل بينها مئات العقد أو تقع في مستندات مختلفة ضمن **مجموعة مستندات مترابطة**، بدل الاقتصار على الخطأ المحلي أو الفقرات المتجاورة.

## Document Set

أضيفت طبقة `review_document_set` التي:
- تستقبل مستندًا طويلًا واحدًا أو عدة مستندات مرتبطة منطقيًا.
- تمنح كل Node هوية namespaced مرتبطة بمصدرها.
- تبني ذاكرة واتساقًا مشتركين للمجموعة.
- تحفظ مصدر الدليل كي يمكن معرفة هل التعارض داخل المستند أم عابر للمستندات.
- تعيد Semantic Issues وFact Conflicts دون خلط Node IDs بين الملفات.

لا يعني ذلك أن أي ملفين مستقلين يجب مقارنتهما تلقائيًا؛ Cross-Document Review يعمل داخل **Consistency Scope** واحد لمستندات مرتبطة بالمشروع/النسخة/الحزمة نفسها.

## تصميم Benchmark V1

النسخة النهائية تحتوي 28 حالة:
- 14 Long-Range.
- 14 Cross-Document.

حالات Long-Range الأساسية تفصل الأدلة المتعارضة بـ 420 عقدة فاصلة، أي إن الاختبار لا يعتمد على التجاور.

التغطية:
- Definition conflicts.
- Abbreviation conflicts.
- Polarity conflicts.
- Decision conflicts.
- Production-capacity fact conflicts.
- Execution-duration conflicts.
- Negative controls للادعاءات المتشابهة غير المتعارضة.
- تتبع أن أدلة Cross-Document تأتي فعلًا من أكثر من مستند.
- Scoped facts حسب السنة والسيناريو والموقع والمرحلة.

## مسار التقوية

الطبقة الأساسية الأولى اجتازت 20/20.

بعد إضافة Scoped-Fact adversarial controls هبطت النتيجة إلى:
- 22/28 = 78.6%.
- 6 حالات فشل.

كانت حالات الفشل الست **3 فجوات منطقية حقيقية** ظهرت مرتين: مرة Long-Range ومرة Cross-Document:
1. قيم السعة الإنتاجية في سنتين مختلفتين كانت تُعامل كتعارض.
2. قيم السيناريو الأساسي والمتحفظ كانت تُعامل كتعارض.
3. قيم موقعين/مصنعين مختلفين كانت تُعامل كتعارض.

حالة اختلاف مدة التنفيذ بين مرحلتين مختلفتين كانت سليمة أصلًا ولم تنتج False Positive.

## الإصلاح

تمت إضافة Semantic Scope Signature إلى مفاتيح الادعاءات الرقمية.

المحددات الصريحة التي تفصل الادعاء حاليًا:
- السنة.
- السيناريو.
- الموقع/المصنع/الفرع/المنشأة.
- المرحلة.

إذا تطابق Scope، يستمر اكتشاف اختلاف القيمة كتعارض. وإذا اختلف Scope الصريح، لا يدمج نَضِيد الادعاءين قسرًا.

## Regression Guards

أضيفت:
- CONF-005: سنتان مختلفتان لا تعارض.
- CONF-006: سيناريوان مختلفان لا تعارض.
- CONF-007: موقعان مختلفان لا تعارض.
- CONF-008: السنة نفسها + قيمتان مختلفتان = تعارض.
- CONF-009: السيناريو نفسه + قيمتان مختلفتان = تعارض.
- CONF-010: الموقع نفسه + قيمتان مختلفتان = تعارض.
- CONF-011: مرحلتان مختلفتان لا تعارض.

## قاعدة الإصدار

أي تغيير في الاتساق يجب ألا:
1. يعيد False Positives بين Scopes صريحة مختلفة.
2. يخفي تعارضًا عندما يكون Scope نفسه.
3. يفقد مصدر الدليل بين المستندات.
4. يكسر Long-Range detection بسبب المسافة أو Chunk boundaries.
