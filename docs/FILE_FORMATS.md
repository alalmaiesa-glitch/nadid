# صيغ المستندات في نَضِيد

## المبدأ

نَضِيد يقبل أي مستند يمكن استخراج محتواه وبنيته منه بصورة موثوقة وآمنة. لا يُبنى المحرك على صيغة واحدة؛ بل تُحوّل الملفات إلى **Normalized Document Model** قبل المراجعة.

## النطاق المعتمد للاستيراد

- DOCX
- PDF النصي
- PDF الممسوح ضوئيًا عبر OCR
- ODT
- RTF
- TXT
- Markdown
- HTML
- EPUB
- PPTX
- XLSX / CSV عبر مسار جدولي منفصل لمراجعة النصوص مع حماية الأرقام والصيغ

## قاعدة القبول

تُقبل الصيغة عندما يتوفر لها Adapter يحقق:
1. التحقق من سلامة الملف ونوعه.
2. استخراج المحتوى القابل للمراجعة.
3. إنشاء عقد مستقرة مع source anchors.
4. حماية الأرقام والحقائق.
5. تسجيل حدود الاستخراج أو فقدان التنسيق بوضوح.
6. عدم الادعاء بإمكانية إعادة بناء التنسيق الأصلي إذا لم يكن ذلك مضمونًا.

## نموذج المعالجة

File → Type Detector → Adapter → Normalized Document Model → Chunker → Document Memory → Fact Lock → Review → Export Adapter

## التصدير

التصدير مستقل عن الاستيراد. قد يقبل نَضِيد صيغة للقراءة والمراجعة دون أن يعيد إنتاجها بنفس الشكل. الأصل محفوظ دائمًا، ويُعرض للمستخدم فقط نوع التصدير الذي يمكن إنشاؤه بأمان.
