# Large Document Scale & Performance Regression V1

## الهدف

نَضِيد منتج مخصص للمستند العربي الطويل، لذلك لا تكفي اختبارات الصحة اللغوية وحماية المعنى وسلامة DOCX والرندر. يجب أن يبقى المسار نفسه قابلًا للتشغيل كلما ازداد حجم المستند.

هذه الطبقة تضيف Regression Benchmark تشغيليًا يراقب:

- Parsing.
- Chunking.
- Protected Spans.
- Arabic Review.
- Document Memory.
- Determinism للعقد والاقتراحات.
- Python allocation peak عبر `tracemalloc`.
- نمو الزمن والذاكرة بعد تطبيعهما بعدد العقد.

## Fixtures

V1 تولّد مستندات DOCX عربية صناعية طويلة داخل الاختبار نفسه، ولا ترفع أي مستند خاص إلى Git.

الحالات:

- `SCALE-001`: 500 فقرة.
- `SCALE-002`: 1,500 فقرة.
- `SCALE-003`: 3,000 فقرة.

تتضمن Fixtures:

- عناوين دورية.
- فقرات عربية مهنية.
- أخطاء لغوية قابلة للرصد.
- أرقام وسنوات ومبالغ محمية.
- جداول دورية.
- شروط والتزامات لغرض Memory/Protection.

## ما الذي يفشل CI؟

V1 لا تستخدم رقمًا صغيرًا للزمن بوصفه SLA؛ GitHub Actions بيئة مشتركة وقد تختلف سرعتها.

بدلًا من ذلك يوجد مستويان:

1. **Absolute catastrophe guards**
   - حد زمني واسع لكل حجم.
   - حد واسع لقمة تخصيصات Python.

2. **Normalized growth guards**
   - نقارن نمو الزمن بنمو عدد العقد.
   - نقارن نمو الذاكرة بنمو عدد العقد.
   - الفشل يحدث فقط إذا زاد النمو المطبّع بصورة واضحة عن الحد المحافظ.

بهذا نلتقط تراجعًا مثل O(n²) أو تسرب ذاكرة كبير دون جعل CI هشًا بسبب تقلبات طفيفة.

## Determinism

كل Fixture يعاد تحليله خارج نافذة القياس، ويجب أن تبقى:

- Node IDs متطابقة.
- Suggestion IDs متطابقة.

إعادة determinism لا تدخل ضمن Performance Budget حتى لا تختلط كلفة التحقق بقياس المسار الأساسي.

## Measurement limits

- `tracemalloc` يقيس تخصيصات Python، وليس RSS الكامل للعملية أو كل تخصيصات مكتبات C.
- أزمنة CI ليست وعدًا بزمن استجابة المنتج.
- الأرقام تصلح كـRegression Guard ومؤشر اتجاهي فقط.
- قياس API end-to-end الحقيقي تحت حمل متزامن يبقى طبقة مستقلة عن هذا Benchmark.

## قاعدة الإصدار

أي تغيير في Parser أو Chunker أو Protection أو Arabic Review أو Document Memory يجب ألا:

1. يكسر determinism.
2. يخفض مخرجات المراجعة المتوقعة فجأة.
3. يتجاوز حدود الانهيار الزمنية/الذاكرية.
4. يظهر نموًا غير منضبط مع زيادة حجم المستند.
5. يكسر أي طبقة جودة سابقة.
