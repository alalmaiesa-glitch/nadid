# مدفوعات نَضِيد

## المزوّد

Moyasar هو المزوّد الأساسي المقترح لنَضِيد.

## الاستخدامات

نفصل كل عملية مالية حسب الغرض:

- `support` — مساهمة اختيارية في تطوير نَضِيد.
- `service` — شراء خدمة أو رصيد أو معالجة مدفوعة.
- `subscription` — اشتراك دوري في خطة نَضِيد.

## التدفق

```
المستخدم
  ↓
اختيار المبلغ أو الخطة
  ↓
Moyasar Payment Form
  ↓
3-D Secure / وسيلة الدفع
  ↓
callback
  ↓
تحقق Server-side من:
  status + amount + currency
  ↓
payments table
  ↓
Webhook للمزامنة النهائية
```

## المتغيرات

```env
NEXT_PUBLIC_MOYASAR_PUBLISHABLE_KEY=
MOYASAR_SECRET_KEY=
MOYASAR_WEBHOOK_SECRET=
```

المفتاح السري لا يرسل إلى المتصفح مطلقًا.

## المساهمات الحالية

واجهة الدعم تعرض:

- $5
- $10
- مبلغ آخر

وهي مساهمة اختيارية ولا تمنح صلاحيات مدفوعة.

## الخدمات المدفوعة لاحقًا

الجداول الحالية تهيئ:

- `payments`
- `billing_plans`
- `subscriptions`

وبذلك يمكن إضافة خطط شهرية/سنوية أو شراء رصيد دون تغيير بنية الدفع الأساسية.

## قاعدة أمان

لا نعتمد على نتيجة redirect وحدها. بعد عودة المستخدم من Moyasar يجب جلب العملية من API والتحقق من:

1. أن الحالة `paid`.
2. أن المبلغ يطابق طلب نَضِيد.
3. أن العملة تطابق الطلب.

ثم فقط نحدّث العملية إلى `paid` ونمنح الخدمة أو الرصيد.
