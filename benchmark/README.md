# Nadid Quality Benchmark

هذا المجلد هو مرجع القياس الداخلي لجودة نَضِيد. لا يعتمد التطوير على الانطباع؛ أي تحسين جوهري يجب أن يُقاس على حالات ثابتة قبل اعتماده.

## الأبعاد المقاسة

- language: الإملاء والترقيم والصياغة الأساسية
- style: الركاكة والتكرار والتحسينات الأسلوبية
- protection: حماية الأرقام والتواريخ والنفي والمعرّفات والمعنى المحمي
- conflict: اكتشاف التعارضات داخل المستند
- context: استرجاع السياق المناسب عبر المستند
- negative: منع الإيجابيات الكاذبة على النص السليم

## القاعدة

1. لا تُحذف حالة فاشلة لتجميل النتيجة.
2. أي خطأ حقيقي يكتشفه المستخدم يتحول إلى حالة Benchmark دائمة.
3. لا يُرفع حد النجاح بخفض صعوبة الحالات.
4. تُحفظ النتائج حسب الإصدار لمراقبة Regression.
5. أي ميزة جديدة لا تعد مكتملة حتى تضيف حالات تقيس نجاحها وفشلها.

## التشغيل

من جذر المستودع:

```bash
PYTHONPATH=backend python benchmark/run_benchmark.py
```

لإنشاء تقرير JSON:

```bash
PYTHONPATH=backend python benchmark/run_benchmark.py --report benchmark/report.json
```

النسخة الأولى Report-Only لتثبيت خط الأساس الحالي. بعد تثبيت خط الأساس ستتحول الحدود الأساسية إلى Quality Gates في CI.
