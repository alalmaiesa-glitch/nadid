# نَضِيد

**نَضِيد — محرر العربية الذكي**

منصة لتحرير ومراجعة المستندات العربية الطويلة، مع التركيز على التدقيق اللغوي والصياغة، فهم السياق على مستوى المستند، اتساق المصطلحات، وحماية الأرقام والحقائق والمعنى أثناء التحرير.

## الواجهة الحالية

- الصفحة الرئيسية: `/`
- رفع المستند: `/upload`
- نموذج المحرر: `/editor`

## التشغيل محليًا

`npm install`

`npm run dev`

ثم افتح `http://localhost:3000`.

## التقنية

Next.js + React + TypeScript + RTL Arabic-first UI.
